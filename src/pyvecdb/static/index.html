    GET STARTED / WINDOWS POWERSHELL

    Run it on your machine

    Open a terminal in the project folder, then run these commands:

    py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
pyvecdb serve --demo

    Then open http://127.0.0.1:8000. --demo loads the sample collection. Stop the server with Ctrl + C.

    Already installed?

    From the project folder, run pyvecdb serve --demo. If the command isn’t found, activate the virtual environment above or use python -m pyvecdb serve --demo.
